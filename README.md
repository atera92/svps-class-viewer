# SVPS クラス別ビューア

Shadowverse Premier Series 26-27 の公式アーカイブを、**クラス（対面）ごとに切り出して連続再生する**ためのツール。

## 使い方

`起動.command` をダブルクリック → ブラウザが開く。それだけ。

第1節〜第7節後半の **全120バトルが最初から登録済み**。手作業は要らない。

止めるとき: `pkill -f "http.server 8899"`

## マリガン早見表

`mulligan.html`（ビューア上部の「マリガン早見表」から開ける）。
現環境のローテーション各デッキについて、先攻・後攻それぞれのキープ推奨カードを、信頼できる発信者の情報から集計した表。

- **印刷 / PDFで保存**：ブラウザの印刷画面が開く。いま表示している出典・クラスだけが出力される
- **PDFをダウンロード**：全クラス・基準を満たす出典のみのPDF（`mulligan.pdf`）

### 出典の選び方（信頼度）

| 区分 | 条件 | 初期表示 |
|---|---|---|
| プロ | プレミアシリーズ26-27所属。公式サイトの選手データ（Xアカウント付き）で本人確認 | 集計に含める |
| 元プロ | 過去のプロリーグ在籍を本人のプロフィールか公式情報で確認 | 集計に含める |
| 実力者 | BEYOND（最高ランク）到達の経験がある、または現在BEYOND（本人の記載・Dexelの紹介で確認）。公式大会の優勝などそれを上回る実績も可。フォロワー数は問わない | 集計に含める |
| 上位プレイヤー（基準外） | 上位の実績は本人記載だが上の条件を満たさない | 含めない（切り替えで表示） |
| 攻略サイト | Game8・GameWith（筆者不明） | 含めない（切り替えで表示） |

対象は**今季（第9弾実装の2026-08-27以降）**に公開・投稿されたものだけ。

### Xからの集め方

画像のマリガン表も読むため、ログイン済みのChromeでXを検索した。

1. プロ37名のアカウントを指定して「マリガン／キープ」「画像つき」で検索
2. デッキ名（別名込み）＋マリガンで15デッキ分を検索（いいね10以上に絞り、反応の多い投稿から探す）
3. Dexel掲載の実力者8名のアカウントを指定して検索
4. ヒットした投稿者のプロフィール（フォロワー数・実績）を確認し、上の区分に振り分けた

画像はカード上部に印字された名前を拡大して読んだ。略称（例：イスマル）は、プレミアシリーズで使われた
全200デッキから作った公式カード名の辞書（`svps_api.py` が参照する公式デッキページの通信先から取得）と照合して正式名にした。
特定できなかった略称はそのまま注記している。

2026-09-10 時点の結果：集めた投稿124件のうち、基準を満たすマリガン情報はプロ2名（TBT・Winter）と
実力者の投稿2件（ふじのん・Figole）。**プロの画像つき投稿39件にマリガン表はなかった**（大半はデッキリスト告知・ランク報告）。
使わなかった投稿と理由は、ページ末尾に一覧で載せている。

2026-09-10 に実力者の条件を「フォロワー1万人以上」から「BEYOND到達（過去・現在）」に変えた。
基準外だった8人のうち7人が実力者になり、表が出るデッキは9 → 11（テンポエルフ・ランプドラゴンが追加）。

## プロの配信から読むマリガン（mulligan.html の「プロの配信（ランクマッチ）」）

プロがYouTubeで配信したランクマッチの映像から、**配信者本人の元の手札4枚・返したカード・交換後の4枚**を
自動で読み取って表にする。SNSの早見表と違い、「プロが実際に何を残して何を返したか」の記録になる。

```bash
python3 mull_stream.py <動画ID> --player まっつ --class ウィッチ --deck 魔手ウィッチ
```

仕組み（`mull_stream.py`）

1. ヘッドレスのChromeで配信を開き、全体を4秒おきに撮って、本人視点のマリガン画面（上段の「CHANGE」の帯）が映る時刻を探す
2. 見つけた場面を等倍で再生し、0.25秒おきに撮る（動画ファイルは保存しない）
3. 本人視点のマリガン画面は、上段 CHANGE（返すカード）・下段 KEEP（残すカード）。カードは列を保って上下に動くので、
   確定直前に上段にあったカードが「返したカード」、確定後に下段にそろった4枚が「交換後の手札」
4. デッキリストが無いので、候補はそのクラスとニュートラルの全カード（公式カード一覧から取得）。
   **絵柄では照合しない**（別イラスト・コラボ絵柄があるため）。コスト・攻撃力・体力・カード名の部分と、
   カードの種類（下の宝石の有無、名前の帯の色）で当てる。公式サイトにある別イラストの画像も照合に使う
5. 先攻・後攻は右下「あなたの手番」の表示で読む
6. 相手のクラスと勝敗は、確認用の画像（`cache/stream_review/`）を見て手で入れる

**全試合を確認用の画像で目視確認してから公開する。** まっつさんの 2026-09-10 の配信（19試合）では、読み取りの誤りはなかった。
配信者ごとに画面の飾りは違うが、ゲーム画面そのものが全画面で映っていれば同じ位置で読める。
ゲーム画面を縮小して配信している人・スマホ縦画面の人は、位置を測り直す必要がある（`mull_read.py` の `LAYOUTS`）。

## プレミアシリーズのマリガン（作成中）

`mull_scan.py` がリーグ配信の観戦画面（上段 GUEST・下段 OWNER）から両プレイヤーのマリガンを読む。
公式のデッキリストがあるので候補を16種前後に絞れる。全120バトルの読み取りと目視確認が済むまで、
ページには表示しない（`mull_pro.json` の `ready` が true になったら表示される）。

### 集計のしかた

- カード名の左の数字は、そのカードをキープに推した**人の数**（同じ人の記事と投稿は1人として数える）
- **出典の大半は先攻・後攻を区別していない**。区別のないキープは両方の列に載せ、
  「先攻のみ」「後攻のみ」は出典が明示したものに限っている。推測で振り分けてはいない

### 更新について

試合データと違い、**マリガン表は自動では更新されない**（投稿や記事の文章・画像を読んで整理しているため）。
中身は `mulligan.json` にあり、2026-09-10時点のもの。環境が変わったら作り直す必要がある。
PDFは次のコマンドで作り直せる（ローカルサーバ起動中に実行）。

```bash
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless --disable-gpu --no-pdf-header-footer --virtual-time-budget=10000 --print-to-pdf=mulligan.pdf "http://localhost:8899/mulligan.html?class=all&src=pass"
```

## 友人と使う

サイトとして公開すれば、**リンクを送るだけ**で使ってもらえる。
相手はMacもインストールも要らない。ブラウザだけでいい。

```
https://atera92.github.io/svps-class-viewer/
```

### リンクで場面を共有する

「リンクをコピー」ボタンを押すと、**いまの絞り込みと再生位置を含んだURL**がコピーされる。
それを送れば、相手は同じ条件・同じ場面から見始められる。

- 選んでいるクラス・「両方を含む」の状態・節/チーム/選手の絞り込み
- いま開いている動画と再生位置（秒）

### データの共有

公式データ（`data.json`）はリポジトリに入っているので、全員が同じ試合データを自動で持つ。
新しい節が配信されたら、**`公開.command` をダブルクリック**すれば
データの更新とサイトへの反映がまとめて実行される。友人はページを再読み込みするだけ。

自分で手作業で足したタグは各自のブラウザにしか残らない。全員に配りたい場合は
「書き出し」したJSONを `data.json` に上書きしてから `公開.command` を実行する。

## スマホから見る

`起動.command` を実行すると、ターミナルに**スマホ用のアドレス**が表示される。
それを iPhone のブラウザで開く（例: `http://192.168.0.17:8899/index.html`）。
一度開いたら「ホーム画面に追加」しておくとアプリのように使える。

条件は2つだけ。

- iPhone が **このMacと同じWi-Fi** に繋がっていること
- **Macがスリープしていない**こと（サーバはMacの上で動いているため）

Macの都合でIPアドレスは変わることがある。開けなくなったら `起動.command` を実行し直して
表示されたアドレスを見る。

スマホでは自動的に縦1カラムになり、プレイヤーが画面上部に固定される。
タグ付けパネルは畳まれている（`▸ タグ付け` で開く）。ヘッダの `⋯` で
URL入力・書き出し・読み込みが出る。

### スマホでの制約

- iOSは**ユーザーが触っていない状態での再生開始を制限する**ため、連続再生の自動送りが
  止まることがある。その場合は次の試合を手でタップする
- データはブラウザごとに保存される。**Macで付けたタグはiPhoneには自動では移らない**。
  移したいときはMacで「書き出し」→ そのJSONを `data.json` として
  このフォルダに置く（次に開いたとき両方に入る）

## 何ができるか

右上のクラスボタンを押して **「上から連続再生」** を押すと、該当する試合だけが
**動画をまたいで**順に再生される。試合の切れ目（カード紹介・作戦タイム・インタビュー）は
範囲から除外してあるので、対戦部分だけが流れる。

### クラスボタンの動き

- **1つ押す** → そのクラスが出ている試合すべて（対面は問わない）。例: ロイヤル → 18件
- **複数押す** → 押したクラスの**どれかが**出ている試合（和集合）。例: ロイヤル＋ナイトメア → 31件
- **ちょうど2つ押したときだけ**「いずれかを含む / 両方を含む」の切替が有効になる。
  「両方を含む」にすると、その2クラスがぶつかっている試合だけになる。例: ロイヤル×ナイトメア → 2件
- **クリア**で全解除
- 一覧は**最初に押したクラスが必ず左に来る**よう向きが揃う（見比べやすくするため）
- 各バトルに **公式のデッキリストへのリンク**が付いている（「デッキ」）
- `↗` でその時刻のYouTubeを直接開ける

## データはどこから来ているか

手入力ではなく、2つの公開データを突き合わせて自動生成している。

1. **公式サイトの内部API** `ps.shadowverse-wb.com/rcms-api/1/schedule-results` が、全バトルの
   **選手名・使用クラス・勝敗・デッキリストURL** をJSONで返す
2. **YouTubeの概要欄チャプター**に `ROUND1開始 / BATTLE1 / BATTLE2 ...` の時刻がある

1がクラス、2が時刻を提供する。両者は**概要欄の「ROUND1：チームA VS チームB」でチーム名照合**して
結び付けている（並び順に依存しない）。バトル数が食い違う場合は生成時に警告が出る。

API内部の対応付けは `schedule.round.roundN.module_id → result.topics_id`、
`result.reference.module_id → decks.topics_id`。この処理は `svps_api.py` にまとめてある。

> 2026年9月に公式サイトがクライアント側描画に変わり、HTMLからは試合結果を読めなくなった。
> それ以前はHTMLに埋め込まれた `session-modal-data` を読んでいたが、現在はAPIを直接使っている。

終了時刻は「次のチャプターの開始時刻」。だから作戦タイムやインタビューは自然に除外される。

## 配信直後の「開始時刻 未設定」について

公式は配信のしばらく後にYouTubeのチャプターを付ける。付く前に更新すると、
**クラス・選手・勝敗だけ先に入り、開始時刻が「未設定」の状態**で登録される
（公式サイトの試合結果は配信直後から公開されているため）。

この状態でも一覧・絞り込みには出る。すぐ見たいなら、その動画を開いて試合の頭に合わせ、
行の **⏱ ボタン**を押せばそこが開始時刻になる。終了時刻は次の試合を打った時点で自動で決まる。

あとで公式がチャプターを付けてから `公開.command` を実行し直すと、
**暫定で打った時刻は公式の正確な時刻に自動で置き換わる**（重複はしない）。
放っておいても問題ない。

## 新しい節が配信されたら

`更新.command` をダブルクリック。一覧の取得とデータ生成をまとめて実行する。
ビューアを開き直すと、**まだ持っていないバトルだけ**が追加される（自分で足した分は消えない）。

個別に実行する場合:

```bash
python3 update_archives.py && python3 build_data.py
```

公式サイトに動画リンクが載らない回がある（第4節がそうだった）。その場合は
`update_archives.py` の `MANUAL` に videoId を追記する。

## 手でタグを足す

チャプターが無い動画（他大会、切り抜き、副音声など）は手作業で登録できる。
ヘッダの入力欄にYouTubeのURLを貼って読み込み、下のパネルで:

1. 試合の開始位置に合わせる
2. 左のクラスを `1`〜`7`、右のクラスを `Z`〜`M`
3. `S` で登録

終了時刻は打たなくてよい。次の試合を登録した時点で、そこまでが前の試合の範囲になる。

### キー操作

| キー | 動作 |
|---|---|
| `Space` | 再生 / 停止 |
| `←` `→` | ±10秒 |
| `Shift` + `←` `→` | ±60秒 |
| `,` `.` | ±3秒 |
| `1`〜`7` | 左のクラス |
| `Z` `X` `C` `V` `B` `N` `M` | 右のクラス |
| `S` | 現在位置で登録（編集中なら更新） |
| `D` | 直前の試合をここで終了 |
| `Esc` | 編集をやめる |
