# SVPS クラス別ビューア

Shadowverse Premier Series 26-27 の公式アーカイブを、**クラス（対面）ごとに切り出して連続再生する**ためのツール。

## 使い方

`起動.command` をダブルクリック → ブラウザが開く。それだけ。

第1節〜第5節前半の **全77バトルが最初から登録済み**。手作業は要らない。

止めるとき: `pkill -f "http.server 8899"`

## 友人と使う

サイトとして公開すれば、**リンクを送るだけ**で使ってもらえる。
相手はMacもインストールも要らない。ブラウザだけでいい。

```
https://atera92.github.io/svps-class-viewer/
```

### リンクで場面を共有する

「リンクをコピー」ボタンを押すと、**いまの絞り込みと再生位置を含んだURL**がコピーされる。
それを送れば、相手は同じ条件・同じ場面から見始められる。

- 選んでいるクラス・「両方を含む」の状態・節/チーム/選手の絞り込み
- いま開いている動画と再生位置（秒）

### データの共有

公式データ（`data.json`）はリポジトリに入っているので、全員が同じ77バトルを自動で持つ。
新しい節が配信されたら、**`公開.command` をダブルクリック**すれば
データの更新とサイトへの反映がまとめて実行される。友人はページを再読み込みするだけ。

自分で手作業で足したタグは各自のブラウザにしか残らない。全員に配りたい場合は
「書き出し」したJSONを `data.json` に上書きしてから `公開.command` を実行する。

## スマホから見る

`起動.command` を実行すると、ターミナルに**スマホ用のアドレス**が表示される。
それを iPhone のブラウザで開く（例: `http://192.168.0.17:8899/index.html`）。
一度開いたら「ホーム画面に追加」しておくとアプリのように使える。

条件は2つだけ。

- iPhone が **このMacと同じWi-Fi** に繋がっていること
- **Macがスリープしていない**こと（サーバはMacの上で動いているため）

Macの都合でIPアドレスは変わることがある。開けなくなったら `起動.command` を実行し直して
表示されたアドレスを見る。

スマホでは自動的に縦1カラムになり、プレイヤーが画面上部に固定される。
タグ付けパネルは畳まれている（`▸ タグ付け` で開く）。ヘッダの `⋯` で
URL入力・書き出し・読み込みが出る。

### スマホでの制約

- iOSは**ユーザーが触っていない状態での再生開始を制限する**ため、連続再生の自動送りが
  止まることがある。その場合は次の試合を手でタップする
- データはブラウザごとに保存される。**Macで付けたタグはiPhoneには自動では移らない**。
  移したいときはMacで「書き出し」→ そのJSONを `data.json` として
  このフォルダに置く（次に開いたとき両方に入る）

## 何ができるか

右上のクラスボタンを押して **「上から連続再生」** を押すと、該当する試合だけが
**動画をまたいで**順に再生される。試合の切れ目（カード紹介・作戦タイム・インタビュー）は
範囲から除外してあるので、対戦部分だけが流れる。

### クラスボタンの動き

- **1つ押す** → そのクラスが出ている試合すべて（対面は問わない）。例: ロイヤル → 18件
- **複数押す** → 押したクラスの**どれかが**出ている試合（和集合）。例: ロイヤル＋ナイトメア → 31件
- **ちょうど2つ押したときだけ**「いずれかを含む / 両方を含む」の切替が有効になる。
  「両方を含む」にすると、その2クラスがぶつかっている試合だけになる。例: ロイヤル×ナイトメア → 2件
- **クリア**で全解除
- 一覧は**最初に押したクラスが必ず左に来る**よう向きが揃う（見比べやすくするため）
- 各バトルに **公式のデッキリストへのリンク**が付いている（「デッキ」）
- `↗` でその時刻のYouTubeを直接開ける

## データはどこから来ているか

手入力ではなく、2つの公開データを突き合わせて自動生成している。

1. **公式サイト** `ps.shadowverse-wb.com/26-27/schedule-results/` の
   `<script id="session-modal-data">` に、全バトルの
   **選手名・使用クラス・勝敗・デッキリストURL** がJSONで埋め込まれている
2. **YouTubeの概要欄チャプター**に `ROUND1開始 / BATTLE1 / BATTLE2 ...` の時刻がある

1がクラス、2が時刻を提供する。両者は**概要欄の「ROUND1：チームA VS チームB」でチーム名照合**して
結び付けている（並び順に依存しない）。バトル数が食い違う場合は生成時に警告が出る。

終了時刻は「次のチャプターの開始時刻」。だから作戦タイムやインタビューは自然に除外される。

## 新しい節が配信されたら

`更新.command` をダブルクリック。一覧の取得とデータ生成をまとめて実行する。
ビューアを開き直すと、**まだ持っていないバトルだけ**が追加される（自分で足した分は消えない）。

個別に実行する場合:

```bash
python3 update_archives.py && python3 build_data.py
```

公式サイトに動画リンクが載らない回がある（第4節がそうだった）。その場合は
`update_archives.py` の `MANUAL` に videoId を追記する。

## 手でタグを足す

チャプターが無い動画（他大会、切り抜き、副音声など）は手作業で登録できる。
ヘッダの入力欄にYouTubeのURLを貼って読み込み、下のパネルで:

1. 試合の開始位置に合わせる
2. 左のクラスを `1`〜`7`、右のクラスを `Z`〜`M`
3. `S` で登録

終了時刻は打たなくてよい。次の試合を登録した時点で、そこまでが前の試合の範囲になる。

### キー操作

| キー | 動作 |
|---|---|
| `Space` | 再生 / 停止 |
| `←` `→` | ±10秒 |
| `Shift` + `←` `→` | ±60秒 |
| `,` `.` | ±3秒 |
| `1`〜`7` | 左のクラス |
| `Z` `X` `C` `V` `B` `N` `M` | 右のクラス |
| `S` | 現在位置で登録（編集中なら更新） |
| `D` | 直前の試合をここで終了 |
| `Esc` | 編集をやめる |

## ファイル

| ファイル | 中身 |
|---|---|
| `index.html` | 本体（単一ファイル・依存ライブラリなし） |
| `data.json` | 全77バトルの試合データ（自動生成） |
| `archives.json` | アーカイブ一覧（自動生成） |
| `build_data.py` | data.json を作る |
| `update_archives.py` | archives.json を作る |
| `起動.command` / `更新.command` | ダブルクリック用 |

データはブラウザの localStorage が作業用コピー。自分で編集した分は「書き出し」でJSONに保存できる。
